# Retail Sales Performance Analysis

**Status: Project setup — analysis has not started.**

A portfolio project planned to explore retail sales using SQL and Power BI. The goal is to turn transaction data into clear measures, a dashboard, and evidence-based business findings.

## Business questions

- How do sales change over time?
- Which product categories contribute the most sales?
- How do regions or stores compare, if those fields are available?
- What is the average order value, if order identifiers are available?
- How does profitability vary, if reliable cost or profit data is available?

## Planned workflow

1. Select a public or synthetic dataset and confirm its usage terms.
2. Document its source, fields, row meaning, and limitations.
3. Check missing values, duplicates, dates, returns, and numeric fields.
4. Define metrics and write SQL queries; reconcile totals.
5. Build a Power BI dashboard and add screenshots.
6. Write findings supported by query outputs and dashboard evidence.

## Current deliverables

This repository contains the project outline and documentation templates. No dataset, executed SQL analysis, dashboard, or findings have been published yet.

## Data handling

Use only data that is permitted for public portfolio use. Do not upload employer, customer, student, or other private records. Record source and usage terms before publishing any data. Raw files are excluded by the starter `.gitignore`; this is a convenience, not a privacy guarantee.
